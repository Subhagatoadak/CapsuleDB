# capsule-studio

Status: **not started** — Phase 7 in the [roadmap](../README.md#phase-7--capsule-studio).

Will be the TypeScript dashboard/inspection interface: source-to-capsule
lineage viewer, evidence viewer, confidence/uncertainty viewer,
contradiction review, capsule comparison, approval workflow, dependency
impact viewer, evaluation report viewer, capsule health dashboard, and
role-based access control. Built on `sdk-typescript` and `capsule-api`.
