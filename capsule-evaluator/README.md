# capsule-evaluator

Status: **not started** — Phase 6 in the [roadmap](../README.md#phase-6--epistemic-evaluation-engine).

Will implement the evaluation architecture from the top-level README
("Evaluation surface reduction"): claim decomposition, mapping answer
claims to supporting capsules, and deterministic detectors for
unsupported claims, applicability expansion, inference-to-fact
conversion, association-to-causation conversion, confidence-ceiling
violations, missing mandatory qualifications, and contradiction
suppression — with bounded LLM-as-a-judge only for residual semantic
questions.
