# capsule-compiler

Status: **not started** — Phase 3 in the [roadmap](../README.md#phase-3--capsule-compiler).

Will transform source material (PDF, text, Markdown, HTML) into candidate
capsules: claim extraction, qualification/limitation pairing, source-span
binding, epistemic-status classification, applicability/exception
detection, confidence-inflation detection, and a human review workflow —
producing `draft`-lifecycle capsules validated by `capsule-core` before
they ever reach `capsule-registry`.
