# capsule-runtime

Status: **not started** — Phase 5 in the [roadmap](../README.md#phase-5--capsule-runtime).

Will serve capsules locally (embedded) or remotely: signed capsule
verification, policy enforcement, purpose-bound access, consumer-specific
views, local cache/offline mode, sync with a central registry, update
subscriptions, and revocation propagation. `capsule-api` and the
`sdk-python`/`sdk-typescript` clients build on top of this.
